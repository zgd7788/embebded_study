# 2026-10-15 任务 0.21：核对板端架构与当前用户

## 目标与前置条件

- 阶段 0；任务 0.20 首次登录操作通过，已收到 `[root@buildroot]:~#`。
- 使用当前 Ubuntu minicom 窗口、ST-LINK 串口及已运行的开发板，无需安装工具、改线或重启。
- 唯一目标：用实际命令核对板端架构与当前用户，区分目标系统和 Ubuntu 开发主机。

## 必要概念与预测

minicom 在 Ubuntu 中运行，但当前登录后的 Shell 在开发板上执行命令。`uname -m` 查询运行系统报告的机器架构；`id -un` 显示当前有效用户 ID 对应的用户名。仅凭架构名称不能证明 ELF ABI、glibc 符号版本等全部兼容。

执行前，先预测目标板的架构是否与 Ubuntu 主机的 x86_64 相同。

## 学习者任务

在当前 `[root@buildroot]:~#` 后逐条执行：

```sh
uname -m
id -un
```

提交两条命令和实际输出，并说明与 Ubuntu 主机架构是否相同。本项仅查询信息，不修改系统。
