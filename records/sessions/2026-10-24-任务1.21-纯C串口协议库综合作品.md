# 任务 1.21：纯 C 串口协议库综合作品

日期：2026-10-24。阶段 1，任务 1.21 开始。

架构与验收基准：[任务1.21-架构与预期结果](../labs/任务1.21-架构与预期结果.md)（2026-10-25 更新）。模块职责、目标接口、超时规则、测试输入与预期输出以该文档为当前设计；本文件保留学习过程和证据。

## 目标

综合运用固定容量缓冲区、串口帧、校验、增量解析、超时状态机、模块接口、严格编译、GDB 和边界测试，构建一个主机可测试的纯 C 协议库。当前只做模拟数据，不连接开发板。

## 计划模块

- 固定容量 RX 环形缓冲区。
- 帧格式：SOF、LEN、CMD、payload、CRC。
- CRC-8 校验及增量式解析，覆盖拆包、粘包、非法长度和坏 CRC 后恢复。
- 基于调用者提供的毫秒 tick 的超时状态机，不在库内直接读取系统时钟。
- 头文件与源文件分离，测试仅通过公开 API 操作。
- GDB 普通/条件断点、调用栈、变量和内存查看。

## 阶段验收门槛

- 自有代码通过 `-std=c11 -Wall -Wextra -Werror`。
- 空输入、最大/越界长度、坏 CRC、拆包/粘包和超时恢复均通过。
- 使用 GDB 完成普通断点、条件断点、变量与内存查看。
- 能说明至少 5 类变量的内存区域和生命周期。
- 阶段闭卷测验和阶段作品分别不低于 80 分。

## 教学顺序

先理解 CRC 与累加和校验的区别，确定 CRC-8 参数及测试向量；再分别学习 CRC 模块、帧格式、增量解析、RX 环形缓冲区和超时状态机；最后集成为协议库并验收。每个函数按学习者约定写“功能、参数、返回值”注释。学习者独立实现，教师讲解、只读审阅和维护记录，不代搭完整工程或执行测试。
