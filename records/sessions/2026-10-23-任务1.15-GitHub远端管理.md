## 补讲：通配符与本地仓库、远端仓库

学习者询问 `**` 的含义，并推测尚未关联 GitHub 就无法执行之前的命令。当前为概念补讲，不代表实际命令已失败。

- `.gitignore` 的 `*` 匹配名称中的任意数量字符，但不跨越 `/`；`**/` 可匹配零层或多层目录。因此 `**/*.exe` 覆盖根目录的 `main.exe` 以及深层目录中的 `learning/practice/c_study/main.exe`。这里的 `*.exe` 单独成行、不带斜杠，也能匹配任意层级相应文件名称；`**/` 并非必须，只是显式表示任意目录层级。
- 本地 `study/.git` 已存在，之前成功的 status 输出就是本地仓库可用的证据。工作区、暂存区和提交历史均可在本机管理。
- `git add`、`git diff --cached`、`git commit` 操作本地仓库，不要求远端地址或网络；`git remote add` 配置远端地址，后续 `git push` 才把提交发送到 GitHub。
- 因此尚未关联 GitHub 不妨碍当前暂存练习。此前 dubious ownership 是本地仓库所有权检查，继续用单次 `-c safe.directory=...` 处理，与远端是否关联无关。
