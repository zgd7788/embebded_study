# 任务 1.14：首次状态轨迹推演审阅

## 学习者回答

学习者写道：“状态分别为TURN_ON、ERROR、TURN_OFF、RESET。第一次不触发，触发变为ERROR，触发变为TURN_OFF，触发变为RESET。共触发3次回调。”

## 审阅与纠正

- 整段序列的回调总数确为 3，但逐步判断不正确；不能只凭总数一致验收。
- `TURN_ON`、`ERROR`、`TURN_OFF`、`RESET` 是输入事件，不是状态。状态是 `OFF`、`ON`、`FAULT`。处理后的状态要从状态转移表读取。
- 第一事件 `OFF + TURN_ON -> ON` 已由教师示范，状态改变并触发 `OFF -> ON` 回调一次。后续事件需从 `ON` 接着追踪。
- 正确的完整轨迹供复核：

| 当前状态 | 输入事件 | 处理后状态 | 回调 |
|---|---|---|---|
| OFF | TURN_ON | ON | OFF -> ON |
| ON | TURN_ON | ON | 无，状态未变 |
| ON | ERROR | FAULT | ON -> FAULT |
| FAULT | TURN_OFF | FAULT | 无，状态未变 |
| FAULT | RESET | OFF | FAULT -> OFF |

回调总数为 3。随后教师检查 `FAULT + TURN_OFF` 这一行，学习者回答：“新状态还是FAULT，不触发回调，因为前后状态没有发生改变。”回答正确，状态未改变则不触发回调这一概念检查点通过。首次推演问题已纠正；状态机编码部分仍待完成。

## 下一步：状态机与回调实现

回调类型声明：

```c
typedef void (*sm_state_change_cb_t)(sm_state_t old_state, sm_state_t new_state);
```

`sm_state_change_cb_t` 表示指向函数的指针；目标函数接收旧、新状态两个参数且不返回值。状态机保存调用者提供的函数地址，只在状态改变时调用。回调可以为 `NULL`，表示未注册通知函数。

类型声明：

```c
typedef enum {
    SM_OFF,
    SM_ON,
    SM_FAULT
} sm_state_t;

typedef enum {
    SM_EVENT_TURN_ON,
    SM_EVENT_TURN_OFF,
    SM_EVENT_ERROR,
    SM_EVENT_RESET
} sm_event_t;

typedef void (*sm_state_change_cb_t)(sm_state_t old_state, sm_state_t new_state);

typedef struct {
    sm_state_t state;
    sm_state_change_cb_t on_change;
} sm_t;
```

`sm_state_t` 是状态类型，`sm_event_t` 是事件类型；`sm_t` 保存当前状态与回调指针。

| 当前状态 | TURN_ON | TURN_OFF | ERROR | RESET |
|---|---|---|---|---|
| OFF | ON | OFF | FAULT | OFF |
| ON | ON | OFF | FAULT | OFF |
| FAULT | FAULT | FAULT | FAULT | OFF |

函数接口与契约：

```c
int sm_init(sm_t *sm, sm_state_t initial_state, sm_state_change_cb_t callback);
int sm_handle_event(sm_t *sm, sm_event_t event);
```

- `sm_init`：`sm` 非空且初始状态合法时保存初始状态和回调指针，返回 0；初始化本身不触发回调，`callback == NULL` 合法。空指针或非法初始状态返回 -1，结构体不变。
- `sm_handle_event`：调用者须传入已初始化的结构体。`sm == NULL`、当前状态非法或事件非法时返回 -1，状态不变且不调用回调。有效事件返回 0，依表确定新状态；若改变，先更新 `sm->state`，再在回调非空时调用一次并传入旧、新状态。状态未变则不调用回调。
- 不动态分配内存；范围仅为主机上的单线程状态模拟，不涉及外设、中断或并发。

验收要求：源码审阅确认初始化和事件处理符合契约、状态/事件所有表项映射正确、变化时回调至多一次且参数次序正确、不变化及非法输入不误调用回调。函数通过后不保留逐项测试输出；教师不代写实现或搭建项目。
