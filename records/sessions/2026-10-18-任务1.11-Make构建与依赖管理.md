### 复习笔记：用途与最小语法

1. gcc 负责实际编译和链接；make 根据规则决定要执行哪些命令，Makefile 是保存这些规则的文本文件。make 并不是另一个 C 编译器。
2. 普通规则写成“目标: 依赖文件”，下一行写执行命令，默认以真实 Tab 开头。目标是希望生成的文件，依赖是会影响它的输入，命令说明如何生成它。
3. 局部教学示范（由学习者手动写入 Makefile，教师不代建）：

```makefile
main.o: main.c reg_sim.h
	gcc -std=c11 -g -O0 -Wall -Wextra -Werror -c main.c -o main.o
```

4. main.o 是目标；main.c 和 reg_sim.h 是依赖。头文件声明为依赖用于告诉 make 何时重编，不表示将头文件当作独立 C 源文件编译。
5. -c 表示编译到对象文件，不进行链接；-o main.o 指定输出文件。main.o 不是可直接运行的完整程序，后续仍需与 reg_sim.o 链接。
6. -std=c11 指定 C11；-g 添加调试信息；-O0 关闭优化；-Wall/-Wextra 启用常见及额外警告；-Werror 将警告作为错误。
7. 对这里的普通文件规则，目标不存在，或某个依赖的修改时间比目标新时，需要执行命令；都未变化时不必重复编译。make 不是逐次比较源代码内容。
8. Makefile 内容写在文件中；make main.o 才是在 Ubuntu Shell 中执行的命令。文件命名为 Makefile，不带 .txt。
