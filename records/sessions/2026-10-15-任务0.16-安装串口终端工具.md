## 必要讲解与操作

`apt` 是 Ubuntu 的软件包管理工具。`apt update` 更新可用软件包的索引，不会把系统中所有软件升级；`apt install minicom` 安装指定工具及其所需依赖，已安装时也会报告状态。

在 Ubuntu 依次执行，每一步成功后再继续：

```bash
sudo apt update
sudo apt install minicom
minicom --version
```

安装提示确认时，阅读软件包变更后输入 `y` 并回车。预期最后一条输出版本信息；它只验证工具能执行，不打开串口。

如果更新、安装或版本检查出现错误，停止并提交错误原文。成功时提交 `minicom --version` 的输出。
