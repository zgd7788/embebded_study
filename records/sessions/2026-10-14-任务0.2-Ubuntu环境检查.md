# 2026-10-14 任务 0.2：Ubuntu 主机环境检查

## 任务目标

确认学习者 Ubuntu 26.04 的系统架构和基础构建工具状态，为后续选择课程工具链建立真实基线。

## 操作边界

- 只执行只读查询命令，不安装、删除或修改系统配置。
- 命令由学习者在自己的 Ubuntu 主机执行；教师不代为搭建环境。
- 不需要连接或烧写开发板。

## 请执行

```bash
cat /etc/os-release
uname -m
git --version
gcc --version
make --version
gdb --version
command -v arm-linux-gnueabihf-gcc
command -v aarch64-linux-gnu-gcc
df -h ~
```

如果某个命令提示 `command not found`，保留原样，不要自行安装；把完整输出发回用于下一步判断。
