# 2026-10-13 任务 0.1b：动态加载器

## 任务目标

理解 Linux 中一个文件明明存在，执行时却可能报告 `No such file or directory` 的原因。

## 核心知识

动态链接程序启动时，Linux 不只需要程序文件本身，还需要 ELF 文件中指定的**动态加载器**。动态加载器负责装入程序依赖的共享库并启动程序。

因此，文件确实存在但执行时报 `No such file or directory`，一种重要可能是：程序要求的动态加载器在目标板上不存在。随后还应继续检查共享库依赖。

以后实操会使用：

- `file 程序名`：查看架构、格式以及动态链接信息。
- `readelf -l 程序名`：查看 ELF 请求的解释器/动态加载器。
- `ldd 程序名`：在合适环境中查看共享库依赖；不能对不可信程序随意使用。

## 当前检查题

如果 ARM Linux 程序文件明明存在，执行时却提示 `No such file or directory`，除了路径写错之外，可能缺少什么？

学习者回答：可能缺少动态链接器。

评价：正确。这里更准确的名称是 ELF 动态加载器或 ELF 解释器；“动态链接器”表达了正确方向。
