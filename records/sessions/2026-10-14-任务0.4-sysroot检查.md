# 2026-10-14 任务 0.4：查看交叉编译器 sysroot

## 当前阶段与目标

- 阶段 0：入门准备与基线。
- 本任务目标：查看交叉编译器报告的 sysroot 路径，初步认识目标头文件和库所在的位置。

## 已知前置

- 主机原生 GCC 目标为 x86-64 Linux。
- 交叉编译器目标三元组为 `arm-linux-gnueabihf`。
- 目标三元组不能单独证明 sysroot、ABI 和共享库版本与 FS-MP1A 当前系统匹配。

## 概念

sysroot 是交叉编译时供编译器/链接器查找目标平台头文件和库的一棵目录树。它不是开发板当前文件系统的自动镜像；之后必须结合 SDK、板端系统信息和实际编译/运行结果验证兼容性。

## 学习者任务

在自己的 Ubuntu 26.04 终端只执行以下只读命令，并把输出原样发回：

```bash
arm-linux-gnueabihf-gcc -print-sysroot
```

不要安装软件、修改配置或连接/操作开发板。

## 验收标准
