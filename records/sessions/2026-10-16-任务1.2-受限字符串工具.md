## 实验要求

编写 `bounded_string.c`，实现一个受限长度字符串复制函数：

```c
size_t bounded_copy(char *dst, size_t dst_size, const char *src);
```

要求：

- 将 `src` 复制到 `dst`，最多写入 `dst_size - 1` 个有效字符，并确保 `dst` 以 `\0` 结尾。
- `dst_size == 0` 时不能写入任何字节，函数返回 0，不解引用 `dst`。
- 返回实际复制的字符数，不包含结尾 `\0`。
- `src` 为空指针时不得解引用；由你决定并记录返回值/错误策略，要求行为明确且可测试。
- 允许源字符串长度等于或超过目标缓冲区，不能越界写入。
- 使用数组作为测试缓冲区，至少覆盖目标容量 0、1、5 和足够容纳源字符串的情况。

程序应在 `main` 中构造测试用例并打印：源字符串、目标容量、复制长度、目标结果；不要使用 `strcpy` 直接替代实现。可以使用 `strlen` 做测试或辅助，但核心复制逻辑必须自己完成。

```c
size_t bounded_copy(char *dst, size_t dst_size, const char *src)
{
    for(size_t i = 0; i < dst_size; i++)
    {
        if(*(src+i) != '\\0')
        {
            *(dst+i) = *(src+i);
        }
        else
        {
            *(dst+i) = '\\0';
        }
    }
    return 0;
}
```

源码审阅结论：未通过。

- 当源字符串长度大于等于 `dst_size` 时，循环会写入 `dst_size` 个源字符，没有空间保证目标字符串以 `\\0` 结尾；`dst_size=1`、非空源字符串即可复现。
- 返回值恒为 0，没有返回实际复制字符数；例如复制 `"abc"` 到足够大的缓冲区也应返回 3。
- `src == NULL` 且 `dst_size > 0` 时会解引用空指针；必须定义并实现明确策略。`dst_size == 0` 时循环本身不写入，但不能掩盖非零容量下的空指针问题。
- 源字符串较短时反复写入 `\\0` 不构成主要错误，但逻辑可以简化为复制到结束后补一个终止符。
