# 2026-10-14 任务 0.5：交叉编译器搜索目录

## 当前阶段与目标

- 阶段 0：入门准备与基线。
- 本任务目标：查看 ARM 交叉编译器配置的库搜索目录，初步理解目标三元组、sysroot 和实际搜索目录共同影响编译/链接。

## 前置结论

- 目标三元组：`arm-linux-gnueabihf`。
- `-print-sysroot` 输出：`/`。
- sysroot 是查找环境的一部分；单独看 sysroot 不能判定 GCC 最终选择的库架构，也不能证明与板端兼容。

## 学习者任务

在自己的 Ubuntu 26.04 终端只执行以下只读命令，并把完整输出发回：

```bash
arm-linux-gnueabihf-gcc -print-search-dirs
```

重点观察 `libraries:` 项。暂时不执行安装、配置变更、编译或板端操作。

## 验收标准

- [x] 提供命令的实际输出。
- [x] 输出包含 `libraries:` 中带有 ARM 目标特征的路径，例如 `/usr/lib/arm-linux-gnueabihf/`。
- [x] 不把目录名本身当作库文件架构或板端 ABI 兼容的最终证据。
