## 必要概念与任务

`mount` 显示当前挂载关系。关注挂载点为 `/` 的行：前面的设备或特殊来源是根文件系统来源，括号中的内容通常包含文件系统类型和挂载选项。`/dev/mmc*` 是常见的 MMC/eMMC/SD 设备命名，但设备名仍需结合实际输出解释。

在当前板端 Shell 执行：

```sh
mount
```

提交包含 ` on / ` 的行，以及输出中出现的 `/dev/mmc*` 相关行（若有）。只读取，不执行 `mount -o remount`、`fdisk`、`parted`、`resize2fs` 或其他存储修改命令。

## 验收与状态

统一标准见 `input/Agent.md` 任务 0.23。

学习者提交的关键挂载行：

```text
/dev/mmcblk2p4 on / type ext4 (rw,relatime)
/dev/mmcblk2p5 on /root type ext4 (rw,relatime)
```

结果：根目录 `/` 实际来自 `/dev/mmcblk2p4`，类型为 `ext4`，以读写方式挂载；`/root` 单独来自 `/dev/mmcblk2p5`。这证明运行中的根文件系统位于 MMC 块设备分区上，并与此前 `resize2fs` 输出的 ext4 场景相互吻合。

边界：`mmcblk2` 这一名称只能证明 Linux 将它识别为 MMC 块设备，不能单独区分板载 eMMC 与可插拔 SD 卡，也不能证明 BootROM/U-Boot 的启动来源。根分区挂载证据与启动介质证据分别记录。
