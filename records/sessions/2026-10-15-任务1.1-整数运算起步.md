## errno.h 与 echo $? 补讲

学习者询问：“errno.h是什么，并且echo $?是什么我也不知道”。

### errno.h

`errno.h` 是 C 标准库头文件，不是一个单独的错误处理函数。它让程序能够访问库函数留下的错误状态：

```c
#include <errno.h>
```

其中 `errno` 是一个整数错误状态，`ERANGE` 是表示结果超出范围的标准错误码。`strtol` 可能成功返回一个数，也可能因为数值太大/太小把 `errno` 设为 `ERANGE`；所以典型顺序是：调用前 `errno = 0`，调用后检查 `errno == ERANGE`。不能只看返回值，因为合法输入 `"0"` 的返回值也是 0。

`errno` 不是每次成功调用都会自动清零，因此调用前清零是为了让本次结果可判断。它只说明库函数报告的错误状态，不能代替 `endptr` 检查：`end == text` 表示没有读到数字，`*end != '\0'` 表示还有未转换字符。

### echo $?

Ubuntu Shell 会在每条命令结束后保存该命令的退出状态。`$?` 是 Shell 变量，`echo` 把它打印出来：

```bash
./calc 12 + 5
echo $?
```

第二条命令必须紧跟第一条，否则 `$?` 会变成上一条命令（例如 `echo` 或其他命令）的状态。通常约定 0 表示成功，非 0 表示失败；Shell 不关心 C 程序内部的 `return -1` 语义，只接收一个 8 位退出状态，因此 `return -1` 常显示为 255。建议 C 错误路径使用 `return 1` 等正的非零值，更容易阅读；正常路径使用 `return 0`。
