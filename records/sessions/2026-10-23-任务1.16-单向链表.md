## 数据结构与不变量

在 learning/practice/c_study/ 下使用学习者自己的源文件和工程组织方式：

    typedef struct list_node {
        int value;
        struct list_node *next;
    } list_node_t;

    typedef struct {
        list_node_t *head;
        list_node_t *tail;
        size_t size;
    } int_list_t;

空表满足 head == NULL、tail == NULL、size == 0。非空表从 head 沿 next 恰好到达 size 个节点，最后一个节点为 tail，且 tail->next == NULL。

除 init 外，其余操作要求 list 指向成功初始化且仍有效的对象。调用者不得直接改节点或复制链表对象导致重复释放。

## 接口契约

1. int int_list_init(int_list_t *list)：list 非 NULL 时设置空表不变量并返回 0；list 为 NULL 返回 -1。允许初始化未初始化的可写对象，不读取其旧成员。
2. int int_list_push_back(int_list_t *list, int value)：尾部追加节点。list 为 NULL 返回 -1；malloc 失败返回 -2 且链表不变；成功返回 0，并更新 head/tail/size。
3. int int_list_find(const int_list_t *list, int value, size_t *index_out)：找到首个相等值时写入从 0 开始的下标并返回 0；任一指针为 NULL 返回 -1；未找到返回 -2，且 index_out 原值不变。重复值返回第一次出现的位置。
4. int int_list_remove_first(int_list_t *list, int value)：删除并释放第一个匹配节点。list 为 NULL 返回 -1；找到并删除返回 0，正确维护首节点、尾节点和 size；未找到返回 -2 且链表不变。
5. int int_list_clear(int_list_t *list)：释放所有节点并恢复空表不变量。list 为 NULL 返回 -1；成功返回 0。清空后仍可 push_back，也可再次 clear。

节点使用 malloc(sizeof *node) 分配，每个成功分配的节点必须且仅能释放一次。分配失败必须在修改链表前处理。整数 0 和负数均为有效值。

接口使用补充：init 用于首次初始化或已 clear 的链表，不用于清除仍有节点的链表；直接 init 会丢失已分配节点的地址，造成泄漏。已有数据需先 clear。该限制不要求 init 读取未初始化的旧成员。
