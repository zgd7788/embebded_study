## 学习目标

## counter 是什么

`counter` 是一个简单的计数器模块。它内部保存一个 `uint32_t` 数值，外部代码不能直接访问这个数值，只能通过 API 创建、增加、读取、重置和销毁。嵌入式中可以用类似模块统计事件次数、重试次数、接收字节数或错误次数。本任务重点不是计数算法，而是模块边界、接口契约和对象所有权。

## 练习模块

实现一个隐藏内部结构的 `counter` 模块：

```c
typedef struct counter counter_t;
```

`counter_t` 的成员只能出现在 `counter.c`，调用者只能通过头文件声明的函数操作它。

接口：

每个函数都必须在头文件或源文件中保留“功能、参数、返回值”注释，使用学习者约定的格式。契约如下：

1. `counter_t *counter_create(uint32_t initial)`
   - 功能：动态创建计数器，并将内部计数值设置为 `initial`。
   - 参数：`initial` 为初始计数值。
   - 返回值：成功返回计数器指针；内存分配失败返回 `NULL`。
2. `void counter_destroy(counter_t *counter)`
   - 功能：销毁计数器并释放其动态内存。
   - 参数：`counter` 为 `counter_create` 返回的对象指针；允许为 `NULL`。
   - 返回值：无。
3. `int counter_add(counter_t *counter, uint32_t delta)`
   - 功能：将 `delta` 加到计数器当前值上。
   - 参数：`counter` 为有效计数器指针；`delta` 为增加量。
   - 返回值：成功返回 `0`；`counter == NULL` 返回 `-1`。本任务不额外处理无符号溢出。
4. `int counter_get(const counter_t *counter, uint32_t *value_out)`
   - 功能：读取计数器当前值并写入调用者提供的输出变量。
   - 参数：`counter` 为有效计数器指针；`value_out` 为可写的输出地址。
   - 返回值：成功返回 `0`；任一指针为 `NULL` 返回 `-1`。
5. `int counter_reset(counter_t *counter, uint32_t value)`
   - 功能：将计数器当前值改为 `value`。
   - 参数：`counter` 为有效计数器指针；`value` 为新的计数值。
   - 返回值：成功返回 `0`；`counter == NULL` 返回 `-1`。

## 文件边界

- `counter.h`：包含必要标准头文件、前置声明和函数声明，不定义 `struct counter` 的成员。
- `counter.c`：定义 `struct counter` 及所有函数实现。
- `counter_test.c`：只包含 `counter.h`，不能包含 `counter.c`，验证公开 API。
