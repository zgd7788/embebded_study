## 功能与用途

固定容量 FIFO 字节队列，用于练习接收字节先存入、后按顺序处理的缓冲思路。数组用到末尾后索引回到开头，复用已读出的空间，不搬移整段数据。本练习只在主机模拟，不实现 UART 硬件、中断或多线程同步。

队列使用调用者提供的数组：不 malloc，不 free，只借用；调用者保留存储所有权，须保证整个使用期间数组有效。结构体和被引用数组是不同对象，不允许借用已结束生命周期的局部数组。

## 数据结构（教学声明，不提供核心函数实现）

```c
#include <stddef.h>
#include <stdint.h>

typedef struct {
    uint8_t *data;
    size_t capacity;
    size_t read_pos;
    size_t write_pos;
    size_t count;
} ring_buf_t;

int rb_init(ring_buf_t *rb, uint8_t *storage, size_t capacity);
int rb_push(ring_buf_t *rb, uint8_t value);
int rb_pop(ring_buf_t *rb, uint8_t *out);
```

- data：借用的字节数组；capacity：可用字节数。uint8_t 为一个 8 位无符号字节类型（本练习使用支持它的现有工具链）；size_t 用于数组容量和索引。
- read_pos：下次读出位置；write_pos：下次写入位置；count：当前有效字节数。
- 约束：capacity > 0，两个下标始终小于 capacity；0 <= count <= capacity。count == 0 为空，count == capacity 为满，全部容量可用，不保留空槽。
- 下标到数组末尾后回到 0；满时不得覆盖未读字节，空时不得读取旧内容。字节 0 是合法数据，不作空队列标记。

## 完整函数契约

### rb_init

- 功能：绑定数组并建立空队列，不必清零数组。
- 参数：rb 指向可写结构体，可尚未初始化；storage 指向至少 capacity 字节的可写存储，capacity > 0。实际数组长度由调用者保证，函数无法从指针推断。
- 成功返回 0：保存 storage/capacity，read_pos、write_pos、count 均为 0。
- 非法参数 rb/storage == NULL 或 capacity == 0：返回 -1，保持可访问的原队列成员和数组不变；不要先部分修改再报错，不读取未初始化旧成员。
- 再次初始化视为逻辑丢弃旧队列数据，不释放也不清零任何数组。

### rb_push

- 功能：在队尾存入一个 value 字节，按 FIFO 顺序保存。
- 参数：rb 必须已成功初始化，除本函数造成的变化外调用者不破坏成员；value 可为 0～255 任意字节。
- 返回 0：写入一个字节，更新 write_pos 和 count，保持 read_pos 不变。
- 返回 -1：rb == NULL。
- 返回 -2：队列已满。
- 所有失败路径均不修改成员和数组；无需对调用者任意破坏内部成员的行为提供恢复机制。

### rb_pop

- 功能：取出最早入队的一个字节。
- 参数：rb 已成功初始化；out 指向可写 uint8_t，且不与队列结构或数组重叠。
- 返回 0：将该字节写入 *out，更新 read_pos 和 count，保持 write_pos 不变；不要求擦除已读出的存储字节。
- 返回 -1：rb 或 out 为 NULL。
- 返回 -2：队列为空。
- 所有失败路径均不修改成员、数组或可访问的 *out。

## 思考例子

容量 3，依次存入 A/B/C 后满；再存 D 应返回 -2 且不改变原数据。读出 A/B 后存入 D/E，剩余读取顺序应为 C/D/E。这里字符仅用作可读字节示例，不要求字符串结尾，也无需上板。

学习者修正后的 `rb_init`：

```c
int rb_init(ring_buf_t *rb, uint8_t *storage, size_t capacity)
{
    if ((rb == NULL) || (storage == NULL) || (capacity == 0)) {
        return -1;
    }
    rb->count = 0;
    rb->read_pos = 0;
    rb->write_pos = 0;
    rb->capacity = capacity;
    rb->data = storage;
    return 0;
}
```
