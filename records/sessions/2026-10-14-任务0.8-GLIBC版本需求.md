# 2026-10-14 任务 0.8：检查 GLIBC 版本需求

## 当前阶段与目标

- 阶段 0：入门准备与基线。
- 本任务目标：查看 ARM ELF 对 GLIBC 符号版本的需求，了解 `NEEDED libc.so.6` 并不表达完整的最低版本兼容信息。

## 前置知识

- `file` 报告的动态解释器：`/lib/ld-linux-armhf.so.3`。
- `readelf -d` 报告的共享库依赖：`libc.so.6`。
- 动态解释器和共享库依赖的含义不同；上述信息不能证明板端具有匹配 ABI/版本的 libc。

## 学习者任务

在保存 `hello-arm` 的 Ubuntu 终端目录中执行以下只读命令，把完整输出发回，并指出 `libc.so.6` 对应的 GLIBC 符号版本需求：

```bash
readelf --version-info hello-arm
```

不要运行 `hello-arm`，不要连接或操作开发板。

## 验收标准

- [x] 提交命令的实际输出。
- [x] 输出显示 `libc.so.6` 所需版本标签 `GLIBC_2.4` 和 `GLIBC_2.34`。
- [ ] 知道 ELF 记录的需求版本不等于已验证板端库满足需求。
