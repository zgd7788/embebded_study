# 2026-10-14 任务 0.7：查看 ARM ELF 动态库依赖

## 当前阶段与目标

- 阶段 0：入门准备与基线。
- 本任务目标：从 ARM ELF 的动态段查看它声明依赖的共享库，区分动态加载器和共享库依赖。

## 前置证据

- `hello-arm` 是 ARM 32-bit EABI5 ELF。
- `file` 输出其动态解释器为 `/lib/ld-linux-armhf.so.3`。
- 动态解释器负责装载 ELF 并解析动态依赖；它本身不等于程序依赖的全部 `.so` 文件。
- 学习者的 Ubuntu VM 桌面练习目录不在当前助手可见工作区；以学习者提交的源码、命令和原始输出作为证据。

## 学习者任务

在保存 `hello-arm` 的 Ubuntu 终端目录中执行以下只读命令，并把完整输出发回：

```bash
readelf -d hello-arm
```

重点找 `NEEDED` 项。不要运行 `hello-arm`，不要连接或操作开发板。

## 验收标准

- [x] 提交命令的实际输出。
- [x] 找出 `NEEDED` 共享库条目：`libc.so.6`。
- [x] 能区分动态解释器路径与 `NEEDED` 共享库依赖。
- [x] 不据 ELF 元数据推断板端已经具备相同库版本或程序已能在板端运行。
