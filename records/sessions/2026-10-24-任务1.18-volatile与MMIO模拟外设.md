# 任务 1.18：volatile 与 MMIO 模拟外设

日期：2026-10-24。阶段 1，任务 1.18 开始。

## 学习目标

理解嵌入式程序如何通过指针访问内存映射寄存器，掌握 `volatile` 与 `const volatile` 的含义，练习保留寄存器其他位的读改写和字段掩码。任务只使用主机内存模拟寄存器，不直接接触开发板硬件。

## 核心概念

- `volatile` 告诉编译器每次读写都必须保留，寄存器值可能被硬件或中断改变。
- `const volatile uint32_t *` 表示软件不能通过该指针写入，但每次读取仍必须真正访问内存。
- `volatile` 不保证原子性，不会把多条读改写指令变成一个不可打断操作。
- 修改字段时要先清除字段掩码覆盖的位，再写入新值，不能破坏其他控制位。

## 模拟寄存器与接口

在 `gpio_sim.h` 中声明：

```c
typedef struct {
    volatile uint32_t control;
    volatile uint32_t status;
} gpio_regs_t;

typedef struct {
    volatile gpio_regs_t *regs;
} gpio_t;
```

寄存器约定：`control` bit 0 为 ENABLE，bit 1~2 为 MODE（有效值 0~3）；`status` bit 0 为 READY。其他位必须保留。

接口：

1. `int gpio_init(gpio_t *gpio, volatile gpio_regs_t *regs)`：绑定寄存器块；任一指针为 NULL 返回 -1，成功返回 0。
2. `int gpio_set_enable(gpio_t *gpio, int enable)`：设置 control bit 0；enable 只能为 0 或 1，非法参数或 gpio/regs 为空返回 -1，成功返回 0。
3. `int gpio_set_mode(gpio_t *gpio, uint32_t mode)`：设置 control bit 1~2；mode 有效范围 0~3，非法参数或 gpio/regs 为空返回 -1，成功返回 0。
4. `int gpio_get_ready(const gpio_t *gpio, int *ready_out)`：读取 status bit 0，写入 0 或 1；任一指针或 regs 为空返回 -1，成功返回 0。

每个函数必须在 `.c` 定义前使用“功能、参数、返回值”格式注释；`.h` 不重复注释。

## 文件边界
