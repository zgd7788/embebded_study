# 2026-10-14 任务 0.3：交叉编译目标三元组

## 任务目标

查看 ARM 交叉编译器准备为哪类 CPU/系统生成程序。

## 背景

命令名 `arm-linux-gnueabihf-gcc` 提供了线索，但应以编译器报告的目标三元组为准。目标三元组通常包含 CPU/架构、厂商、操作系统和 ABI 线索。

对本任务而言，关注它是否指向 ARM Linux，以及 `gnueabihf` 所表达的 GNU/Linux hard-float ABI 线索。最终是否匹配目标板，仍要与板端系统和 SDK/sysroot 实测比较。

## 学习者提交

目标三元组：`arm-linux-gnueabihf`

学习者说明：该编译器面向 ARM Linux；主机原生 GCC 面向 x86-64 Linux。

## 验收结果

- [x] 提供目标三元组 `arm-linux-gnueabihf`。
- [x] 能区分交叉编译器面向 ARM Linux、主机原生 GCC 面向 x86-64 Linux。
- [x] 未将目标三元组等同于 sysroot/运行库与开发板完全匹配。

结果：通过。得分：100/100（本项概念检查，无板端实操）。
