# 2026-10-14 任务 0.1d：执行权限

## 任务目标

理解 Linux 文件存在并不等于当前用户有权执行它。

## 核心知识

Linux 文件权限通常分为所有者、所属组和其他用户三类，每类都有读、写、执行权限。程序作为命令直接启动时，需要相应的执行权限；目录还需要搜索/进入权限。

常用观察命令是 `ls -l 程序名`，其中权限字符串中的 `x` 表示执行权限。例如：

```text
-rwxr-xr-x
```

这表示所有者、组用户和其他用户都具备执行权限。权限不足时可能出现 `Permission denied`。实际修改权限时由学习者操作，不能把“直接使用 root 绕过问题”当作诊断完成。

## 诊断顺序

```text
架构/格式 -> 动态加载器 -> 共享库 -> 执行权限 -> 运行时配置
```

## 当前检查题

如果程序文件存在、架构正确、动态加载器和共享库也都满足，但系统提示 `Permission denied`，最可能要检查什么？

学习者回答：当前用户是否具有执行权限。

评价：概念正确。还需要识别权限字符串中的执行标记，才能进入后续命令实操。
