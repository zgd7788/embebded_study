# 2026-10-13 任务 0.1c：共享库依赖

## 任务目标

知道动态链接程序除了 ELF 动态加载器，还依赖目标系统中的共享库。

## 核心知识

动态加载器存在，不代表程序一定能启动。程序还可能依赖 `libc.so`、`libstdc++.so` 或其他共享库；库缺失、架构不匹配、ABI 不兼容，都可能导致加载失败。

诊断层次是：

```text
程序文件
  -> 目标架构与 ELF 格式
  -> ELF 动态加载器
  -> 所需共享库及其架构/ABI
  -> 文件权限和运行时配置
```

## 当前检查题

确认程序架构正确、动态加载器也存在后，程序仍因依赖问题无法启动，下一步应该检查什么？

## 验收

- [x] 学习者回答“是否存在共享库和执行权限”。
- 评价：共享库检查正确；执行权限也是必要检查项，但通常在架构、动态加载器和共享库之后检查。
