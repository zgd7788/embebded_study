# 2026-10-15 任务 0.14：配置串口访问用户组

## 目标与前置条件

- 阶段 0，任务 0.13 基础判断通过（90/100），完整判断链待巩固。
- Ubuntu 当前会话不含 `dialout`，设备节点权限为 `crw-rw---- root dialout`。
- 唯一目标：学习者追加用户组，重新登录后验证当前会话包含 `dialout`。设备为现有 Ubuntu VM 与板载 ST-LINK，本任务无需改动接线。

## 原理与操作

`usermod` 修改用户配置；`-aG` 表示追加附加组，保留原有组；`"$USER"` 在普通 Ubuntu 用户终端中展开为当前用户名。

由学习者在 Ubuntu 普通用户终端执行：

```bash
sudo usermod -aG dialout "$USER"
```

命令成功通常没有输出；如有报错，保留原文并停止后续步骤。保存工作后，完整注销 Ubuntu 桌面并重新登录，随后在新终端执行：

```bash
id -nG
```

仅关闭再打开终端不能保证桌面会话的组成员刷新。预期输出包含 `dialout`，并保留原有附加组。配置组成员不等于已成功打开串口或完成通信。
