## 必要讲解

串口两端需要使用匹配的波特率与帧格式。`8N1` 表示 8 个数据位、无校验、1 个停止位；流控用于协调暂停和继续传输。本次先使用 115200 8N1、关闭两类流控作为初始配置；只有 115200 已由学习者根据手册确认，其余值尚未证明与板端匹配。

## 学习者任务

在 Ubuntu 普通用户终端执行：

```bash
minicom -s
```

用方向键选择 `Serial port setup`，回车进入，设置：

| 页面项 | 设置 |
| --- | --- |
| A — Serial Device | `/dev/ttyACM0` |
| E — Bps/Par/Bits | `115200 8N1` |
| F — Hardware Flow Control | `No` |
| G — Software Flow Control | `No` |

按对应字母进入修改；A 输入设备路径并回车；E 子菜单按显示选项选择 115200、8 数据位、无校验、1 停止位，然后回车返回；F/G 是开关，仅当当前值为 Yes 时切换。

先停留在参数页面，抄出 A、E、F、G 四项提交。不要选择 Save setup as dfl；当前是普通用户配置练习，尚不保存系统默认文件。遇到错误保留原文，不通过 sudo 绕过。
