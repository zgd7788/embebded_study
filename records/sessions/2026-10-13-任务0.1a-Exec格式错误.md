# 2026-10-13 任务 0.1a：识别 Exec format error

## 任务目标

遇到板端 `Exec format error` 时，能够说出首要检查的两个属性。

## 学习者表现

- 初次回答：不知道。
- 第二次回答：首先检查目标架构是否是 ARM，二进制文件是否匹配。
- 当前状态：回答正确，任务通过。

## 核心知识

1. **目标架构**：程序面向哪种 CPU 执行。FS-MP1A 的 Cortex-A7 Linux 用户程序通常应匹配 ARM 32 位架构。
2. **二进制格式**：目标系统能否识别该文件格式。Linux 常见格式是 ELF，还要关注 32/64 位、端序和文件类型。

## 正确诊断顺序

```text
Exec format error
  -> 检查目标 CPU 架构是否匹配（例如 ARM）
  -> 检查二进制格式是否匹配（例如 Linux ELF）
```

常用验证工具：`file 程序名`、`readelf -h 程序名`。这些命令由学习者在 Ubuntu 环境中实际执行时再形成命令输出证据。

## 边界说明

- 动态加载器缺失或依赖库问题，通常在确认架构和格式正确后继续检查。
- 复位、时钟属于板卡启动、硬件初始化或外设异常的诊断方向，不是该报错的首要检查。
