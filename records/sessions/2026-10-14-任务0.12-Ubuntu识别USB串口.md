# 2026-10-14 任务 0.12：确认 Ubuntu 识别 USB 串口设备

## 当前阶段与目标

- 阶段 0：入门准备与基线。
- 本任务目标：确认 Ubuntu 主机识别 USB 转串口设备并显示设备标识。

## 前置条件

- 学习者报告 FS-MP1A 调试串口为 TTL、115200，并确认配套转换器兼容；实际连接/通信尚未验证。
- 本任务只把转换器接到 Ubuntu 主机，不连接开发板，不接触板卡针脚。

## 学习者任务

将 USB 转串口设备插入 Ubuntu 虚拟机可见的 USB 端口，不接开发板；先执行：

```bash
ls -l /dev/serial/by-id/
```

学习者报告输出：

```text
ls: cannot access '/dev/serial/by-id/': No such file or directory
```

该结果只说明当前没有此目录；还不能据此判断虚拟机是否识别 USB 转串口设备。下一步再执行只读命令 `lsusb` 查看 USB 枚举结果。不要安装软件，也不要猜测 `/dev/tty*` 设备名。

学习者提交的 `lsusb` 输出：

```text
Bus 001 Device 001: ID 1d6b:0001 Linux Foundation 1.1 root hub
Bus 001 Device 002: ID 0e0f:0003 VMware, Inc. Virtual Mouse
Bus 001 Device 003: ID 0e0f:0002 VMware, Inc. Virtual USB Hub
Bus 002 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
```

当前列表没有 USB 转串口设备条目；只能得出该设备尚未出现在 Ubuntu VM 的 USB 枚举列表中，不能据此断定设备损坏。

学习者随后将设备连接给虚拟机，并提交新的 `lsusb` 输出：

```text
Bus 001 Device 001: ID 1d6b:0001 Linux Foundation 1.1 root hub
Bus 001 Device 002: ID 0e0f:0003 VMware, Inc. Virtual Mouse
Bus 001 Device 003: ID 0e0f:0002 VMware, Inc. Virtual USB Hub
Bus 001 Device 004: ID 0483:374b STMicroelectronics ST-LINK/V2.1
Bus 002 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
```

Ubuntu 已枚举 STMicroelectronics ST-LINK/V2.1（USB ID `0483:374b`）。这确认 USB 设备可见，但尚未确认是否创建了虚拟串口设备节点。

学习者随后查询 `/dev/serial/by-id/`，输出：

```text
total 0
lrwxrwxrwx 1 root root 13 Oct 14 23:14 usb-STMicroelectronics_STM32_STLink_0670FF565556857187182353-if02 -> ../../ttyACM0
```

系统已创建 ST-LINK interface `if02` 到 `/dev/ttyACM0` 的稳定符号链接，说明存在该 USB 设备的串行接口节点。学习者确认该 ST-LINK 是 FS-MP1A 开发板上的接口，因此这是板载 ST-LINK 的虚拟串口（VCP），不是独立 USB-UART 转换器。

## 验收标准

- [x] 提供初次查询的实际输出。
- [x] 根据 `lsusb` 结果判断当前列表未看到转换器。
- [x] VMware 连接后，`lsusb` 可见 ST-LINK/V2.1（`0483:374b`）。
- [x] `/dev/serial/by-id/` 中出现 ST-LINK `if02` 到 `../../ttyACM0` 的链接。
- [x] 确认枚举到的 ST-LINK 是 FS-MP1A 板载接口，识别 VCP 与独立 USB-UART 转换器的区别。

## 学习者结果

首次查询 `/dev/serial/by-id/` 返回 `No such file or directory`；首次 `lsusb` 未见设备。之后虚拟机枚举出板载 ST-LINK/V2.1（`0483:374b`）并创建 `if02 -> ../../ttyACM0`；学习者确认这是 FS-MP1A 板上的 ST-LINK VCP。

## 得分与决定

通过，100/100。理由：Ubuntu 枚举到 FS-MP1A 板载 ST-LINK/V2.1 及其 VCP 设备节点 `/dev/ttyACM0`。尚未测试串口通信或烧录固件。
