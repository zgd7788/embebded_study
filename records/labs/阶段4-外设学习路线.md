# 外设学习路线与当前安排

2026-11-10根据学习者要求整理：先完成UART轮询学习，再继续其他外设；中断暂缓，不作为进入下一外设的前提。本文件是任务安排，不代表所列内容已经完成。

后续衔接：按学习者2026-11-10安排，当前批量收发源码审阅后先进入定时器轮询计时；UART基本错误恢复保留待补，建立可靠时间基准后回补等待超时。定时器实例和输入时钟须先核实，再设计PSC/ARR/CNT与更新标志的轮询练习。

## 近期顺序

| 外设或功能 | 重点 | 练习目标 |
|---|---|---|
| GPIO | 输入输出、上下拉、复用、BSRR、按键消抖 | 已有LED输出基础；输入和消抖按实际资源补齐 |
| UART | 时钟与波特率、FIFO、批量收发、错误恢复 | 基本收发与批量接收回显已验证，批量发送集成源码通过；当前版本上板验证及基本错误恢复待补 |
| 定时器 | 时钟、预分频、计数周期、更新标志、回绕 | 不开中断也能轮询计时；建立可靠时间接口，回补UART等待超时 |
| PWM | 频率、占空比、通道及引脚复用 | 输出可测量PWM，控制合适的LED或蜂鸣器等资源 |
| I2C | 开漏与上拉、地址、START/STOP、ACK/NACK、寄存器读写 | 根据实际板载器件选一个目标，完成读写与NACK/超时处理 |
| SPI | 片选、CPOL/CPHA、全双工、时钟、字节顺序 | 根据实际硬件读器件ID或传感器数据，观察总线时序 |
| ADC | 输入范围、参考电压、采样时间、分辨率、校准 | 先轮询单次采样，做码值到电压换算，理解误差；不先上DMA |
| 看门狗 | 计时与超时、喂狗策略、复位源 | 在确认系统交接状态后练习可控复位，区分异常复位猜测与证据 |

定时器输入捕获作为计时进阶练习，学习测量频率及脉宽；RTC纳入板载资源核对，有访问与验证条件时安排实作。UART超时依赖可靠时间基准，因此在定时器基础之后回补，不在UART阶段强行加入中断节拍。

## 后续保留

A7异常入口与GIC、GPIO外部中断、定时器及UART中断、RAM环形缓冲区、DMA，以及真实UART与阶段1协议库的综合应用。DMA、高级流控和RS-485不作为当前轮询UART收尾的前提。中断是保留任务，只是调整学习顺序。

## 平台和完成标准

阶段4同时重视A7启动、链接和尽可能广的外设实作，不以GPIO/UART/定时器作为范围上限。优先结合FS-MP1A实际板载资源开展GPIO、UART、定时器、PWM、输入捕获、I2C、SPI、ADC、RTC和看门狗；具备异常入口与GIC基础后继续中断和适合的DMA练习。后续M4阶段迁移和深化这些知识，并加入FreeRTOS，不要求所有驱动机械重复手写。

扩展任务先建立板载资源表，逐项记录原理图位置、器件/接口、控制器与引脚、复用、电平、时钟、A7/M4访问及占用情况、验证方式。传感器、EEPROM、Flash、显示和执行器等以核实后的实际资源为准；音频、USB、以太网、SD/MMC、显示及摄像头接口等继续评估，按可行性分层学习，复杂协议栈放到相应阶段。未接出、缺少器件或当前不具备访问条件的项目记录原因和补学安排，不能据芯片功能表宣称板卡已具备。

每类外设按硬件用途与原理图、时钟及寄存器、独立驱动实现、实测、错误处理逐步学习，并通过多外设小实验理解采集、控制、通信和时间要求，为M4与操作系统阶段的任务拆分打基础。该扩展范围是长期教学要求，具体实作状态仍在progress与sessions记录。

每项实作前核对FS-MP1A原理图、实际已连接器件、引脚复用、时钟以及A7/M4资源归属和访问条件，再确定实例和管脚。基础完成标准是能说明硬件与寄存器依据、独立初始化和调用、用波形或数据验证，并具备适合当前阶段的边界及错误处理；不以初始化成功或读写一次代替完整验收。
